# `.claude_pet/pets` — サンプルコンパニオンセット

[English](README.md) · [한국어](README.ko.md) · **日本語** · [Español](README.es.md)

**claude-pet** ですぐに使える、完成済みのカスタムペット集です。
現在 4 種類が含まれています： **Dog · Fox · Scorpion · Elephant**。

> ℹ️ **アプリが自動で入れます — 手でコピーする必要はありません。**
> claude-pet はカスタムペットをホームディレクトリ `~/.claude_pet/pets/` から読み込みます。この
> ツリーはアプリに同梱されて配布され、**起動のたびにホームに無いものだけを補充します**：
> 4 つの `README*.md` は `~/.claude_pet/` 直下へ、各ペットは `~/.claude_pet/pets/<名前>/` へ。
>
> 補充は**「無いものだけ」で、破壊的なことはしません**。既にある README はそのまま、既にある
> ペットフォルダは**丸ごと**スキップします — 中身を見ないので、自分で編集したペットが部分的に
> 上書きされることはありません。何も上書きせず、何も削除しません。
> 標準ペットのフォルダを削除すれば次回起動で戻り、編集したペットは編集したまま残ります。
>
> 安全なインストールを保証できないファイルシステム（一部のネットワーク/マウントされたホーム）では、
> 中途半端なペットを残すくらいなら**ペットだけを見送ります**。`README*.md` 4 つはそのまま作成される
> ことがあるため、これらがあってもペットが入ったとは限りません — `~/.claude_pet/pets/` を確認し、
> 空なら下の「手動コピー」の **2** をお使いください。このようなファイルシステムではペットを削除しても
> 補充されないので、手で作った複製が唯一の複製です。消さないでください。
>
> 設定ファイル `~/.claude_pet.json`（フォルダではなく JSON ファイル）とも別物なので混同しないでください。

## 手動コピー（任意）

アプリが自動で行うため通常は不要です。手動でコピーする場面は次の二つです。

**1. 標準ペットを自分の名前でもう一体置きたいとき** — すでに標準ペットがあり、編集用の複製を
並べたい場合:

```bash
cd ~/.claude_pet
cp -R pets/dog pets/dog-mine        # まだ存在しない名前へ
```

メニューに出る名前はフォルダ名ではなく `pet.json` の `displayName` です。`pets/dog-mine/pet.json` を
開いて `"displayName": "Dog"` を好きな名前に変えるか、その行を削除してフォルダ名を使わせてください。
そのままだとメニューに「Dog」が二つ並びます。

**2. アプリがインストールを見送った場合**（上の注記を参照）。このとき `~/.claude_pet/pets/` は
空なので、コピー元はアプリバンドルの中になります:

```bash
mkdir -p ~/.claude_pet/pets
cp -R /Applications/ClaudePet.app/Contents/Resources/.claude_pet/pets/dog ~/.claude_pet/pets/dog
```

ソースから実行している場合は、同じコピー元がリポジトリの `.claude_pet/pets/dog` にあります。

> ⚠️ どちらの場合も**まだ存在しない名前**へコピーしてください。コピー先が既にある場合、`cp -R` は
> その**中**に複製を作り、`pets/dog/dog/` のような余計なフォルダができます。また名前を指定せず
> `pets/` の中へコピーすると同名ファイルが上書きされ、編集内容が失われます。アプリの自動補充は
> 既にあるペットフォルダに一切触れません — 手で打ったコマンドでそれを起こさないでください。

コピー後、**画面のペットを右クリック → ペットを選択**すると新しいコンパニオンが表示されます。
（メニューバーや Dock のアイコンはありません — メニューは画面上のペットにだけあります。）
メニューは開くたびにフォルダを再スキャンするので、**アプリの再起動は不要**です。

アプリの「ペットフォルダを開く」メニューは、`~/.claude_pet/pets/` が無ければ自動作成し、
使い方ガイド（`README.txt`）を置いてから Finder で開きます。

## フォルダ構成

```
<ペット名>/
├── pet.json          # メタデータ + スプライト規約（必須）
├── spritesheet.webp  # スプライトシート（必須 — 実際に読み込まれる唯一の画像）
└── preview.png       # プレビュー画像（任意、実行時は未使用 — ドキュメント/ギャラリー用）
```

- **ペットの内部 ID はフォルダ名**で決まります。`pet.json` の `id` 値ではありません。
- 実行時に読み込まれるのは `pet.json` と `spritesheet.webp` の**2 つだけ**です。
  `preview.png` はコードから参照されません（リポジトリのプレビュー用）。

## `pet.json` スキーマ

```json
{
  "id": "dog",
  "displayName": "Dog",
  "description": "フレンドリーな犬のコンパニオン …",
  "spriteVersionNumber": 2,
  "spritesheetPath": "spritesheet.webp"
}
```

| フィールド | 必須 | 意味 |
|---|---|---|
| `id` | 推奨 | 識別用。ただしアプリは実際には**フォルダ名**を ID として使用します。 |
| `displayName` | 推奨 | 右クリックメニューに表示される名前。無い場合はフォルダ名になります。 |
| `description` | 任意 | ドキュメント用。実行時には使われません。 |
| `spriteVersionNumber` | 推奨 | スプライトシートの格子規約バージョン。現在は **2** のみ定義。不明な値は v2 にフォールバック。 |
| `spritesheetPath` | 任意 | シートファイルの相対パス。既定値は `"spritesheet.webp"`。 |

---

## スプライトシート規約（spriteVersionNumber 2）

シートは**固定の 8 列 × 11 行グリッド**でスライスされます。

- セルサイズ = `シート幅 / 8` × `シート高さ / 11`
- 同梱ペットはすべて **1536 × 2288** → セルは **192 × 208**
- 各アニメーション状態は、指定の**行（row）**の 0 列目から左 → 右へ、決められたフレーム数だけ埋めます。

| 行 (row) | 状態 | フレーム数 |
|---|---|---|
| 0 | `idle` | 7 |
| 1 | `running-right` | 8 |
| 2 | `running-left` | 8 |
| 3 | `waving` | 4 |
| 4 | `jumping` | 5 |
| 5 | `failed` | 8 |
| 6 | `waiting` | 6 |
| 7 | `running` | 6 |
| 8 | `review` | 6 |
| 9–10 | （予約、未使用） | — |

- **`idle` は必須**です。使用可能な `idle` フレームが無いペットは無効として扱われます。
- 各セルの余白・背景は透明（アルファ）にすることを推奨します。

### アニメーションのタイミング

固定 fps ではなく、状態ごとに**1 フレームあたりの表示時間（ms）**が決まっています（概算）：

| 状態 | 1 フレーム | 再生 |
|---|---|---|
| `idle` | 430ms | ループ（約 25 秒間隔で休止） |
| `waiting` | 340ms | ループ |
| `review` | 360ms | ループ |
| `failed` | 260ms | ループ |
| `waving` | 200ms | 1 回再生 |
| `jumping` | 150ms | 1 回再生 |
| `running` / `running-left` / `running-right` | 90ms | ループ（≈ 11fps） |

記載のない状態は既定値 400ms・ループが適用されます。

## 自分だけのペットを作る

1. `~/.claude_pet/pets/<名前>/` フォルダを作成します。
2. 上記 8×11 グリッド規約に沿って `spritesheet.webp` を配置します（最低限 `idle` 行が必要）。
3. `pet.json` を作成します（`spriteVersionNumber: 2`）。
4. 右クリックメニューを開き直すとペットが表示されます。

> 参考：旧フォーマットも対応しています — `pet.json` の代わりに、`idle/`、`running/` など**状態別サブフォルダ内の
> PNG シーケンス**でもペットを作れます（内蔵のネコがこの方式）。新規ペットは上記シート方式を推奨します。

---

## フォルダが無いとき

`~/.claude_pet/pets/` が無くてもアプリは正常に動作し、既定は**内蔵のネコ（Cat 🐱）**です。
保存したペットが消えたり壊れたりした場合は、自動的にこの内蔵ペットにフォールバックします。
