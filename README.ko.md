## 다운로드 & 설치 (권장)

**Python 설치 불필요** — 앱에 내장돼 있고 **Apple 공증**되어 Gatekeeper 경고 없이 바로 열립니다.

1. [**Releases**](https://github.com/uygnoey/claude-pet/releases/latest)에서 `ClaudePet.zip` 다운로드 — **Intel Mac**은 `ClaudePet-universal.zip`을 받으세요 (v0.10부터 제공)
2. 압축 해제 → `ClaudePet.app`을 **응용 프로그램** 폴더로 이동 → 더블클릭
3. macOS 12+ (Apple Silicon; Intel은 v0.10부터 universal zip 사용)

### 권한 (첫 실행 시)

펫은 **`~/.claude`(급증 알림용 Claude Code 로그)와 키체인의 OAuth 토큰만** 읽고, Codex를 쓰면 `~/.codex`(로그인 파일과 급증 알림용 세션 로그)도 읽습니다. 그 외 폴더(사진·다운로드·문서 등)는 건드리지 않아요. 첫 실행 때 딱 이것만 뜹니다:

| 팝업 | 무엇 | 누를 것 |
|---|---|---|
| **키체인** — "Claude Code-credentials" | 서버 계산 %를 가져올 OAuth 토큰 | **항상 허용** |
| **"다른 앱의 데이터"** — `~/.claude` | 급증 알림용 로그 읽기(숫자만, 이 컴퓨터 안에서) | **허용** |

- 토큰은 **실행당 1회만** 조회하고, 서명된 앱이라 결정이 영구 저장돼 다시 안 물어봅니다.
- **사진/다운로드/음악/데스크탑/문서/iCloud/네트워크볼륨 팝업은 뜨지 않습니다.** (과거엔 `claude` CLI를 자식으로 실행해 그 스캔이 앱에 귀속되며 떴지만, 지금은 CLI 호출을 기본 OFF로 막음)
  - 모델별(Fable) 줄을 CLI로 보충받고 싶으면 `CLAUDE_PET_USE_CLI=1`로 켤 수 있으나, 그러면 폴더 팝업이 다시 뜹니다.

### Claude Code 또는 Codex가 필요해요

이 펫은 **Claude Code 또는 Codex의 사용량**을 보여주는 도구라, 숫자는 각 도구의 로그인으로 받은 서버 %이고 로컬 로그는 급증 알림에만 씁니다. 그래서 **구독 모드는 Claude Code 또는 Codex 설치·로그인이 전제**입니다.

- Claude Code가 없으면 필 대신 **"Claude Code 미설치"** 안내가 뜨고, **우클릭 → "⬇︎ Claude Code 설치…"** 를 누르면 터미널에서 공식 설치([`claude.ai/install.sh`](https://claude.ai/install.sh)) → 로그인까지 진행합니다.
- 설치돼 있는데 로그인만 안 된 경우엔 **우클릭 → "🔑 Claude Code 로그인…"** 으로 바로 로그인할 수 있습니다.
- Claude Code 항목은 로그가 아니라 로그인 토큰으로 판단합니다: 토큰이 없으면 최근 로그가 있어도 항목이 뜹니다.
- Codex도 똑같습니다. 다만 이 컴퓨터에서 Codex를 쓸 때만(`codex` CLI나 `~/.codex` 폴더가 있을 때 — 없으면 아무것도 더하지 않습니다): Codex를 필에 보이는데 로그인이 안 돼 있으면 **우클릭 → "⬇︎ Codex 설치…"**(터미널에서 `npm install -g @openai/codex` 후 `codex login`) 또는 **"🔑 Codex 로그인…"**(`codex login`). Windows에서는 새 PowerShell 콘솔에서 진행합니다.
- 설치/로그인이 끝나면 재시작 없이 다음 갱신에 자동으로 사용량이 표시됩니다.
- 참고: **API 모드**(우클릭 → 설정 → Admin API 키, Codex는 OpenAI Admin API 키)는 로그인 없이도 동작합니다.

### 업데이트

실행 후 1시간마다(시작 시에는 확인하지 않음) GitHub 최신 릴리즈를 확인해, 새 버전이 있으면 **우클릭 → "⬆︎ 새 버전 설치"** 로 다운로드·교체·재실행까지 자동 처리합니다. **우클릭 → "⬆︎ 업데이트 확인…"** 을 누르면 지금 바로 확인해 최신 버전으로 한 번에 설치합니다.

## Windows

Windows 10/11(64비트)에서도 같은 필·산책·설정·펫을 씁니다. 릴리즈마다 두 파일이 올라갑니다.

- **`claude-pet-win-setup.exe`** — 설치 파일. 현재 사용자 계정에 설치하고(관리자 권한 불필요) 시작 메뉴와 "앱 및 기능" 제거 항목을 만들며, **로그인 시 Claude Pet 자동 실행** 옵션을 제공합니다.
- **`claude-pet-win.zip`** — 무설치·갱신용. 아무 곳에나 풀고 `ClaudePet\ClaudePet.exe`를 실행하면 됩니다.

**SmartScreen 경고에 대해.** Windows 판은 아직 코드 서명이 없어서, 설치 파일이나 `ClaudePet.exe`를 처음 실행하면 *"Windows의 PC 보호"* 창이 뜹니다. **추가 정보**를 누른 뒤 **실행**을 누르세요. SmartScreen의 앱 검사가 꺼진 PC에서는 대신 *"파일 열기 - 보안 경고"*(알 수 없는 게시자) 창이 뜨는데, **실행**을 누르면 됩니다. 설치 파일은 어느 쪽이든 한 번만 묻고, 무설치 zip은 *이 파일을 열기 전에 항상 확인*을 끄기(또는 zip 속성에서 차단 해제 후 풀기) 전까지 실행할 때마다 물을 수 있으며, 게시자를 알 수 없다는 안내이지 유해한 것을 발견했다는 뜻이 아닙니다. 브라우저(Edge)가 다운로드를 같은 이유로 막으면 **유지** → **그래도 유지**를 고르세요. 코드 서명이 들어가는 릴리즈부터는 이 경고가 사라집니다.

먼저 Windows에서 Claude Code 또는 Codex에 로그인(`claude` / `codex login`)한 뒤 Claude Pet을 실행하세요. 사용량 숫자는 `%USERPROFILE%\.claude`(또는 `%USERPROFILE%\.codex`)의 자격 파일로 받고, 그 아래 로그는 급증 알림에만 읽습니다. 내 펫은 `%USERPROFILE%\.claude_pet\pets\<이름>\`에 넣습니다(우클릭 → 펫 → 펫 추가…가 그 폴더를 엽니다). 트레이 아이콘은 Windows 기본값 때문에 작업표시줄 오버플로(`^`) 안에 있으니 꺼내 두면 항상 보입니다. 우클릭 → 완전 삭제…는 설정·로그를 지우고, 프로그램 자체는 "앱 및 기능"의 제거 항목으로 지웁니다.

## 직접 빌드 (개발자용)

소스에서 빌드하려면 **framework 빌드 파이썬**이 필요합니다:

- **Homebrew**: `brew install python@3.13` (framework 빌드라 그대로 됨)
- **pyenv**: 반드시 `--enable-framework`로 설치
  ```bash
  PYTHON_CONFIGURE_OPTS="--enable-framework" pyenv install 3.13.14 && pyenv global 3.13.14
  ```
  > ⚠️ 시스템 파이썬(`/usr/bin/python3`, 3.9)은 pyobjc 빌드가 깨지니 쓰지 마세요.

```bash
./build_app.sh install     # 로컬 빌드+서명 → /Applications 설치+실행
python3 claude_pet.py --report   # GUI 없이 터미널 리포트만

./release.sh build         # 배포용 자체포함 앱(py2app); sign / notarize / universal / dmg / publish 는 별도 서브커맨드
```
`release.sh`는 최초 1회 공증 자격증명 등록이 필요합니다(스크립트 상단 주석 참고).

## 행동

- **평소엔 가만히** — 첫 프레임 정지, 25초에 한 번 숨쉬기/깜빡임만
- **마우스가 가까이 가면** 손 흔들며 인사 (쿨다운 30초)
- **스스로 돌아다님** — 쉬다가 마우스가 움직이고 있으면 한 번 다가와 잠깐 바라보고, 아니면 화면 아무 데나
  골라 산책한 뒤 그 자리에서 쉼(제자리로 돌아오지 않음). 커서 위로는 걸어가지 않고, 잡거나 메뉴·설정을 열면 그 자리에서 멈춤
- **가끔 마우스를 따라다님** — 10~20초 동안 거리를 두고 천천히 따라오다가 바라보고, 멈춘 자리에서 쉼.
  **모니터가 여러 개면 가끔 건너다님** — 살짝 점프해 흐려졌다가 다른 화면의 안전한 자리에 나타남
- **걸을 땐 필을 접고** 펫만 움직임. 도착하면 접어 두었더라도 사용량 필을 잠시 보여 주고, 구경이 끝나면
  평소에 해 두었던 대로 되돌아감
- **잡고 끌면** 끄는 방향으로 달리기, **더블클릭** 점프 + **사용량 즉시 갱신**(캐시 무시 재조회)
- **토큰 소비 급증하면** 몸에 경고색 펄스 + 패닉 표정, 필에서 그 제공자의 세션 라벨이 ▲와 함께 빨간색:
  - 🔴 세션(또는 Codex) 급증 / 🟣 모델(Fable/Opus) 급증 / 🟠 주간 급증
  - 급증은 Claude Code와 Codex의 로컬 로그로 판단하고, 기준 한도는 **서버 %에서 스스로 배웁니다** — 설정할 것은 없고,
    배우기 전에는 급증 알림이 없습니다(API 모드인 제공자도 없음)
- **세션 리셋 감지하면**(서버의 세션 %가 5% 초과에서 1% 미만으로) 신나서 점프

## 조작

- **스크롤 (펫 위에서)**: 크기 조절 (0.3×~2.0×, 저장됨. 기본 0.5×)
- **클릭 (⌄ 버튼)**: 사용량 필 접기/펴기
- **드래그**: 이동 (위치 저장)
- **우클릭**: 메뉴 — (필요할 때 Claude Code·Codex 설치/로그인) / 설정 / 접기·펴기 / 화면 돌아다니기(켜기·끄기) / 크기 원래대로 / 펫(고르기·추가) / 완전 삭제 / 종료 / 업데이트 확인

## 사용량 필

펫 옆의 작은 필 하나, 두 줄:

- **첫 줄 — 사용량**: `세션 42% · 주간 17% · Fable 12%` — 세션(5h) / 주간 전체 / 주간 모델별, 서버가 준 값 그대로.
  Codex는 Claude 옆에 자기 마크와 함께 따로 나옵니다. API 모드인 제공자는 비용: `오늘 $3.21 · 이번 달 $27.50`.
- **둘째 줄 — 리셋**: `리셋 세션 3시간 42분 후 · 주간 2일 3시간 후`.
- **숫자는 언제나 서버 값**: 에메랄드 = 서버 계산 %, 코랄 = API 비용. 로그로 추정한 숫자는 보여 주지 않고, 서버 값이 없으면
  상태 문구가 뜹니다(예: "토큰 만료 — Claude Code 한번 실행하면 사용량 복구", 로그인 안내, 두 제공자를 다 끄면 "표시할 제공자가 없어요").
  Codex 로그인이 만료되면 따로 "Codex 토큰 만료 — codex 한번 실행하면 사용량 복구"가 뜹니다.
- **서버가 잠깐 답하지 않아도 숫자는 남습니다**: 새로고침이 요청 한도·서버 오류·네트워크 오류·깨진 응답으로 실패하면 마지막으로 받은
  값을 그대로 두고, 다음 조회가 성공할 때 바꿉니다. 토큰이 거부됐을 때만 지웁니다. 설정을 저장하면 이미 받은 값으로 다시 그리고,
  언어·데이터 소스·Admin 키를 바꿨을 때만 다시 조회합니다.
- **라벨 색 = 잔여량**: 흰색, 50%부터 노란색, 85%부터 빨간색 — 급증 중인 게이지는 ▲와 함께 빨간색.
- 글자는 앱에 내장한 **Pretendard**(SIL Open Font License)로 그려서 어느 기기에서나 같은 모양.

## 내 펫 넣기

우클릭 → **펫**에 내장 고양이와 `~/.claude_pet/pets/` 아래 폴더가 전부 나오고, **펫 추가…**를 누르면 그 폴더가 포맷 안내
README와 함께 열립니다. 펫은 `pet.json` + `spritesheet.webp`가 든 폴더 하나입니다(시트 규약은 README에). 목록은 메뉴를 열
때마다 다시 읽으므로 재시작 없이 바로 보입니다. zip을 풀어 한 단계 더 깊어진 폴더(`pets/이름/이름/pet.json`)도 인식하고
`__MACOSX`는 무시합니다.

## 설정 (우클릭 → 설정)

- **Claude Code**와 **Codex**가 같은 모양의 구역을 하나씩 가짐:
  - **필에 표시** 켜기/끄기
  - **데이터 소스**: 구독(로그인 계정) / API(Admin API 비용 — 오늘·이번 달. 월 예산을 넣으면 필에 `이번 달 $27.50 / $50`처럼 나오고 사용 비율에 따라 "이번 달" 글자가 노랑·빨강으로 바뀜, 금액은 코랄 그대로)
  - **보일 게이지** — Claude Code: 세션 / 주간 / 모델별 / 크레딧, Codex: 세션 / 주간
  - **Admin API 키**와 **월 예산** — Codex는 **OpenAI Admin API 키**
- 그 아래 급증 민감도, 마우스 인사 on/off. 보정할 것은 없음 — 급증 알림의 한도는 서버 %에서 배움.

- **화면 돌아다니기**: 우클릭 메뉴의 체크 항목으로 켜고 끔(기본 켜짐). 마우스 따라다니기와 모니터 건너다니기도
  이 항목에 묶임. macOS 손쉬운 사용의 **동작 줄이기**가 켜져 있으면 움직이지 않음. 스스로 돌아다니거나 건너간
  자리는 저장하지 않고, 드래그해 놓은 자리만 기억함.

모든 설정·크기·위치는 `~/.claude_pet.json`에 저장.

## 한계 (솔직하게)

- 숫자는 서버가 계산한 % 그대로라 Claude·Codex 자체 사용량 화면과 같음. 급증 알림은 로컬 로그 기준이라 웹/데스크톱 채팅 사용량은 미포함.
- Admin API 비용은 Console 조직 것이며 구독 한도와 별개.
- Admin API 키(Anthropic·OpenAI)는 `~/.claude_pet.json`에 평문 저장되니 개인 기기에서만 사용 권장.
