This page covers this website — claude-pet.yeongyu.me. The Claude Pet desktop app is a separate thing and is described further down.

What this website collects

This site uses Google Analytics 4 to count visits. It runs on every page and is not optional — a visit is measured whether or not you do anything here.

Google Analytics receives the pages you open, the link or search that referred you, your browser and device type, and an approximate location derived from your IP address. It does not receive your name, your email, or anything you type.

Advertising is the part that is optional. Google's ad signals — ad_storage, ad_user_data, ad_personalization — are on by default, and you can turn them off below at any time. This site carries no advertising today; the switch is here so the choice is yours before that changes.

Advertising cookies:

Counting visits, above, is required and is unaffected by this switch either way.

Cookies

Google Analytics sets these first-party cookies. Google documents a two-year default; Chrome currently caps cookies set this way at about 400 days, and some browsers keep them for less.

Hosting

The site is served by GitHub Pages. GitHub's own documentation states that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes, whether or not the visitor is signed in to GitHub. That logging belongs to GitHub and is not affected by the choice above.

The desktop app is separate

Claude Pet the app has nothing to do with this website's analytics. It does not contact Google, and it does not report anything to this site. What it does do:

  • Exact mode sends your existing Claude Code credential to Anthropic to ask for your account usage.
  • Update checks and downloads contact GitHub.
  • Usage parsing happens on your computer. Prompts, transcripts and source code are never uploaded by those paths.
  • An optional Admin API key is stored in plaintext in ~/.claude_pet.json on your own machine.
