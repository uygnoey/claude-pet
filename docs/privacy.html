This page covers this website — claude-pet.yeongyu.me. The Claude Pet desktop app is a separate thing and is described further down.

What this website collects

This site uses Google Analytics 4 to count visits. It is off by default: Google Consent Mode starts with storage denied, so no analytics cookie is set and no measurement is recorded until you accept the cookie notice. If you decline, or simply ignore the notice, that stays the case.

Once you accept, Google Analytics receives the pages you open, the link or search that referred you, your browser and device type, and an approximate location derived from your IP address. It does not receive your name, your email, or anything you type.

Cookies

Only after you accept. Both are first-party cookies set by Google Analytics; the durations are Google's documented defaults.

Your own choice is kept in your browser's local storage under claudepet-consent. That never leaves your device, and clearing your browser data removes it.

Withdrawing consent stops any further measurement immediately. Cookies already set are removed by clearing site data in your browser.

Hosting

The site is served by GitHub Pages. GitHub's own documentation states that when a GitHub Pages site is visited, the visitor's IP address is logged and stored for security purposes, whether or not the visitor is signed in to GitHub. That logging belongs to GitHub and is not affected by the choice above.

The desktop app is separate

Claude Pet the app has nothing to do with this website's analytics. It does not contact Google, and it does not report anything to this site. What it does do:

  • Exact mode sends your existing Claude Code credential to Anthropic to ask for your account usage.
  • Update checks and downloads contact GitHub.
  • Usage parsing happens on your computer. Prompts, transcripts and source code are never uploaded by those paths.
  • An optional Admin API key is stored in plaintext in ~/.claude_pet.json on your own machine.
