What do I need to sign in to?

Being signed in to either Claude Code or Codex is enough. If you use both, both are shown.

Where does the usage come from?

For both Claude Code and Codex, it comes from the server, using the login on this computer. Numbers are never estimated from logs; local logs are read only to catch sudden spikes.

Is it free?

It’s free to download and open source. You don’t need to sponsor to use the app.

Which computers does it run on?

macOS 12 or later on Apple Silicon and Intel Macs, and Windows 10 or 11 on x64. There is no separate Windows ARM build.

Does it upload my prompts or code?

No. Local logs are read only on your computer, to catch usage spikes. Your existing Claude Code or Codex login is sent only to Anthropic or OpenAI to ask for your usage, and update checks contact GitHub. Prompts, transcripts and source code are never uploaded.

Why does Windows show a security warning?

The Windows builds are not code-signed, so SmartScreen or another security warning may appear, depending on your system settings and policies. The Mac builds are Developer ID signed and notarized by Apple.

How does it update?

On both macOS and Windows, the app checks for a new release every hour after launch, and “Check for updates…” in the right-click menu downloads and installs it inside the app.

Can I add my own pet?

Yes. Put a compatible pet.json and sprite-sheet folder in ~/.claude_pet/pets on a Mac, or %USERPROFILE%\.claude_pet\pets on Windows, and it appears in the right-click menu.
