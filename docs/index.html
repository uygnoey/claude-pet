Claude Code · Codex

Either one, in the same place

Claude Code.
Codex, too.

Use just Claude Code, just Codex, or both. Usage for whichever you’re signed in to on this computer appears side by side in the same pill, told apart by its logo.

Codex usage is read from the OpenAI API, not from local logs, so only the limits your account actually has are shown. Codex usually has a single weekly limit right now, so one line carries both the usage and the time left until it resets. There’s nothing to set up.

What do I need to sign in to?

Being signed in to either Claude Code or Codex is enough. If you use both, both are shown.

Where does the usage come from?

For both Claude Code and Codex, it comes from the server, using the login on this computer. When Claude Code’s server values can’t be fetched, it is estimated from local logs, and estimates are marked with ≈. Codex doesn’t use local logs.

Is it free?

It’s free to download and open source. You don’t need to sponsor to use the app.
