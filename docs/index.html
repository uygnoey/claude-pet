03 / FIND A HOME ON YOUR DESKTOP

Your desk. Your OS.
Your new companion.

Choose your platform. Python is included in the packaged app. Start by signing in to Claude Code on this computer.

macOS 12+

Apple Silicon · DMG ↗ Intel · Universal DMG ↗

  1. Choose your chip

    Use the Apple Silicon DMG for M-series Macs. Choose the universal DMG for Intel. ZIP alternatives are on the release page.

  2. Move it to Applications

    Open the DMG, drag ClaudePet.app to Applications, then launch it. Mac downloads are Developer ID signed and Apple-notarized.

  3. Connect, then make it yours

    Allow access to the existing Claude Code credential when prompted. It may be in Keychain or the Claude Code credentials file. Right-click the pet for settings.

Windows 10/11 · x64

Windows · EXE ↗ Windows · ZIP ↗

  1. Installer or portable ZIP

    Run claude-pet-win-setup.exe for a per-user install with a Start Menu entry and optional start at sign-in. Or extract the ZIP and open ClaudePet/ClaudePet.exe.

  2. Know what you’re opening

    Windows builds are unsigned. SmartScreen or another security warning may appear; behavior depends on your Windows settings and policies. Download from the project’s GitHub release and review the file before running it.

  3. Use your Windows Claude Code login

    Sign in to Claude Code on Windows first. The app reads its credentials file at %USERPROFILE%/.claude/.credentials.json. Right-click the pet to configure it.

A few things
worth knowing.

Is Claude Pet free?

Yes. Claude Pet is free to download, with public source on GitHub. No particular software license is implied by source availability.

What do I need?

macOS 12 or later on Apple Silicon or Intel, or Windows 10/11 on x64. Sign in to Claude Code on that computer. Python is bundled with the packaged app.

Is this my real Claude usage?

Exact mode shows percentages and reset times returned by Anthropic using your existing Claude Code credential. Local fallback is an estimate of Claude Code logs; web and desktop activity absent from those logs is not included. Optional calibration applies to the estimate.

What leaves my computer?

Exact mode sends your existing Claude Code credential to Anthropic to request account usage. Update checks and downloads contact GitHub. Local usage parsing happens on your computer; those usage and update paths do not upload prompts, transcripts or source code. The optional Admin API key is stored in plaintext in ~/.claude_pet.json (under your Windows user folder on Windows).

Can I use it for API costs or other AI services?

Optional Admin API mode shows Anthropic Console organization costs, separately from subscription limits. This release tracks Claude; do not treat other AI services as supported.

How do updates work?

On Mac, automatic checks begin one hour after launch and repeat hourly. The right-click menu can check and install a newer release. On Windows, use the right-click menu to check, then download the new installer from GitHub Releases.
