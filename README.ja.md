# 🐱 Claude Pet

[English](README.md) · [한국어](README.ko.md) · **日本語** · [Español](README.es.md)

Codex Pets のように、画面に浮かんで Claude Code または Codex の使用量を見守るデスクトップペット。
macOS ネイティブ（AppKit）描画 — ウィンドウ枠・背景・残像なし。

> 🧪 v0.24 — macOS 版は公証済み、Windows 版はインストーラーと zip で提供します（未署名 — 下の Windows 節を参照）。

![Claude Pet](preview.png)

## ダウンロードとインストール（推奨）

**Python 不要** — アプリに同梱されており、**Apple の公証（notarize）済み**なので Gatekeeper の警告なしで開けます。

1. [**Releases**](https://github.com/uygnoey/claude-pet/releases/latest) から `ClaudePet.zip` をダウンロード — **Intel Mac** の場合は `ClaudePet-universal.zip` を選んでください（v0.10 から提供）
2. 展開 → `ClaudePet.app` を **アプリケーション** フォルダへ移動 → ダブルクリック
3. macOS 12+（Apple Silicon; Intel は v0.10 から universal zip で対応）

### 権限（初回起動時）

ペットは **`~/.claude`（急増アラート用の Claude Code ログ）とキーチェーンの OAuth トークン** だけを読み、Codex を使う場合は `~/.codex`（ログインファイルと急増アラート用のセッションログ）も読みます。他のフォルダ（写真・ダウンロード・書類…）には一切触れません。初回起動時に出るのはこれだけです:

| ダイアログ | 内容 | 選ぶ |
|---|---|---|
| **キーチェーン** — "Claude Code-credentials" | サーバー計算の % を取得する OAuth トークン | **常に許可** |
| **「他のAppのデータ」** — `~/.claude` | 急増アラート用ログの読み取り（数値のみ、このコンピュータ内で） | **許可** |

- トークンは **起動ごとに1回だけ** 読み、署名済みアプリなので決定は保存され、二度と聞かれません。
- **写真／ダウンロード／ミュージック／デスクトップ／書類／iCloud／ネットワークボリュームのダイアログは出ません。**（以前はペットが `claude` CLI を子プロセスとして起動し、そのホームスキャンがアプリに帰属して出ていましたが、その CLI 呼び出しは既定でオフにしました。）
  - モデル別（Fable）の行を CLI で補完したい場合は `CLAUDE_PET_USE_CLI=1` を指定できますが、その場合フォルダのダイアログが再び出ます。

### Claude Code または Codex が必要です

このペットは **Claude Code または Codex の使用量**を表示するツールで、数値は各ツールのログインで得たサーバーの % で、ローカルログは急増アラートにだけ使います。そのため **サブスクリプションモードは Claude Code または Codex のインストールとログインが前提**です。

- Claude Code が無い場合はピルの代わりに **「Claude Code 未インストール」** と表示され、**右クリック →「⬇︎ Claude Code をインストール…」** で公式インストーラ（[`claude.ai/install.sh`](https://claude.ai/install.sh)）をターミナルで実行し、続けてログインします。
- インストール済みでログインだけ必要な場合は **右クリック →「🔑 Claude Code にログイン…」** ですぐログインできます。
- Claude Code の項目はログではなくログイントークンで判断します: トークンがなければ、最近のログがあっても項目が出ます。
- Codex も同じです。ただし、このコンピューターで Codex を使っている場合だけです（`codex` CLI か `~/.codex` フォルダーがあるとき — なければ何も追加しません）: Codex をピルに表示していてログインしていない間は **右クリック →「⬇︎ Codex をインストール…」**（ターミナルで `npm install -g @openai/codex` のあと `codex login`）または **「🔑 Codex にログイン…」**（`codex login`）。Windows では新しい PowerShell コンソールで実行します。
- 完了すると再起動なしに次の更新で使用量が表示されます。
- 補足：**API モード**（右クリック → 設定 → Admin API キー、Codex は OpenAI Admin API キー）はログイン無しでも動作します。

### アップデート

起動後 1 時間ごとに（起動時には確認しません）GitHub の最新リリースを確認し、新しいバージョンがあれば **右クリック →「⬆︎ 新しいバージョンをインストール」** でダウンロード・置換・再起動まで自動で行います。**右クリック →「⬆︎ アップデートを確認…」** で今すぐ確認し、最新版へ一度にインストールします。

## Windows

Windows 10/11（64 ビット）でも同じピル・散歩・設定・ペットが使えます。リリースごとに 2 つのファイルを公開します。

- **`claude-pet-win-setup.exe`** — インストーラー。現在のユーザーにインストールし（管理者権限不要）、スタートメニューと「アプリと機能」のアンインストール項目を作り、**サインイン時に Claude Pet を起動**するオプションがあります。
- **`claude-pet-win.zip`** — ポータブル／更新用。任意の場所に展開して `ClaudePet\ClaudePet.exe` を実行します。

**SmartScreen の警告について。** Windows 版はまだコード署名がないため、インストーラーや `ClaudePet.exe` を初めて実行すると *「Windows によって PC が保護されました」* が表示されます。**詳細情報** → **実行** の順にクリックしてください。SmartScreen のアプリ確認がオフの PC では代わりに「ファイルを開く - セキュリティの警告」（発行元不明）が出るので、**実行** を押します。インストーラーならどちらも一度だけですが、ポータブル zip では「このファイルを開く前に常に警告する」を外す（または展開前に zip のプロパティでブロックを解除する）まで起動のたびに出ることがあり、発行元が不明であるという通知であって、有害なものを検出したという意味ではありません。ブラウザ（Edge）が同じ理由でダウンロードを止めた場合は **保持** → **そのまま保持** を選びます。コード署名が入るリリースからこの警告は出なくなります。

先に Windows で Claude Code または Codex にサインイン（`claude` / `codex login`）してから Claude Pet を起動してください。使用量の数値は `%USERPROFILE%\.claude`（または `%USERPROFILE%\.codex`）の資格情報ファイルで取得し、その下のログは急増アラートにだけ読みます。自分のペットは `%USERPROFILE%\.claude_pet\pets\<名前>\` に入れます（右クリック → ペット → ペットを追加… でそのフォルダが開きます）。トレイアイコンは Windows の既定でタスクバーのオーバーフロー（`^`）内にあるので、引き出しておくと常に見えます。右クリック → 完全に削除… は設定とログを消し、プログラム本体は「アプリと機能」のアンインストールで削除します。

## ソースからビルド（開発者向け）

ソースからビルドするには **framework ビルドの Python** が必要です:

- **Homebrew**: `brew install python@3.13`（すでに framework ビルド）
- **pyenv**: `--enable-framework` 付きでインストール
  ```bash
  PYTHON_CONFIGURE_OPTS="--enable-framework" pyenv install 3.13.14 && pyenv global 3.13.14
  ```
  > ⚠️ システムの Python（`/usr/bin/python3`, 3.9）は pyobjc のビルドが壊れるため使わないでください。

```bash
./build_app.sh install     # ローカルでビルド+署名 → /Applications にインストールして実行
python3 claude_pet.py --report   # GUI なしのターミナルレポートのみ

./release.sh build         # 配布用の自己完結アプリ（py2app）; sign / notarize / universal / dmg / publish は別サブコマンド
```
`release.sh` は初回のみ公証用の資格情報の登録が必要です（スクリプト冒頭のコメント参照）。

## 挙動

- **普段はじっとしている** — 最初のフレームで静止、25秒に1回だけ呼吸／まばたき
- **マウスが近づくと** — 手を振って挨拶（クールダウン30秒）
- **ときどき自分で歩き回る** — 普段はその場で休み、マウスが動いていると一度近づいてしばらく見つめ、
  そうでなければ画面のどこかをランダムに選んで散歩し、着いた場所でそのまま休む（元の場所には戻らない）。
  カーソルの上には歩いて行かず、つかんだりメニュー・設定を開くとその場で止まる
- **ときどきマウスについて来る** — 10〜20秒のあいだ距離を保ってゆっくり追いかけ、見つめてから止まった場所で休む。
  **モニターが複数あればときどき渡り歩く** — 小さくジャンプして薄れ、別の画面の安全な場所に現れる
- **歩くときはピルを畳んで** ペットだけが動く。着いたら畳んであっても使用量ピルをしばらく見せ、見終わると
  普段の状態に戻る
- **つかんでドラッグ** — 引っ張る方向へ走る。**ダブルクリック** = ジャンプ + **使用量を即時更新**（キャッシュ無視の再取得）
- **トークン消費が急増すると** — 体が警告色でパルス + パニック顔、ピルではそのプロバイダのセッションラベルが ▲ 付きで赤くなる:
  - 🔴 セッション（または Codex）急増 / 🟣 モデル（Fable/Opus）急増 / 🟠 週間急増
  - 急増は Claude Code と Codex のローカルログで判定し、基準の上限は **サーバーの % から自動で学習** します — 設定は不要で、
    学習するまでは急増アラートは出ません（API モードのプロバイダも出ません）
- **セッションのリセットを検知すると**（サーバーのセッション % が 5% 超から 1% 未満へ） — 喜んでジャンプ

## 操作

- **スクロール（ペットの上で）**: サイズ変更（0.3×〜2.0×、保存。既定 0.5×）
- **クリック（⌄ ボタン）**: 使用量ピルの表示／非表示
- **ドラッグ**: 移動（位置を保存）
- **右クリック**: メニュー — （必要なときは Claude Code・Codex のインストール／ログイン） / 設定 / 表示・非表示 / 画面を歩き回る（オン・オフ） / サイズを元に戻す / ペット（選択・追加） / 完全に削除 / 終了 / アップデートを確認

## 使用量ピル

ペットのそばに小さなピルが一つ、二行:

- **1行目 — 使用量**: `セッション 42% · 週間 17% · Fable 12%` — セッション（5h）/ 週間合計 / 週間モデル別、サーバーの値そのまま。
  Codex は Claude の隣に自分のマーク付きで別に表示。API モードのプロバイダはコスト: `今日 $3.21 · 今月 $27.50`。
- **2行目 — リセット**: `リセット セッション 3時間42分後 · 週間 2日3時間後`。
- **数値は常にサーバーの値**: エメラルド = サーバー計算の %、コーラル = API コスト。ログから推定した数値は表示せず、サーバーの値が
  無いときは状態の文言を出します（例:「トークン期限切れ — Claude Code を一度実行すると使用量が復帰」、ログイン案内、両方のプロバイダを
  オフにすると「表示するプロバイダがありません」）。Codex のログインが期限切れのときは「Codex トークン期限切れ — codex を一度実行すると
  使用量が復帰」と出ます。
- **サーバーが一時的に応答しなくても数値は消えません**: 更新がリクエスト上限・サーバーエラー・ネットワークエラー・壊れた応答で失敗した
  ときは、最後に受け取った値をそのまま表示し、次に取得に成功したときに更新します。消えるのはトークンが拒否されたときだけです。
  設定を保存しても取得済みの値で描き直し、言語・データソース・Admin キーを変えたときだけ取り直します。
- **ラベルの色 = 残量**: 白、50% から黄、85% から赤 — 急増中のゲージは ▲ 付きで赤。
- 文字は同梱の **Pretendard**（SIL Open Font License）で描くので、どのマシンでも同じ見た目。

## 自分のペットを入れる

右クリック → **ペット** に内蔵の猫と `~/.claude_pet/pets/` 以下の全フォルダが並び、**ペットを追加…** でそのフォルダが
フォーマット説明の README と一緒に開きます。ペットは `pet.json` + `spritesheet.webp` を入れたフォルダ一つです（シートの
規約は README に）。一覧はメニューを開くたびに読み直すので、再起動なしですぐ現れます。zip を展開して一段深くなった
フォルダ（`pets/name/name/pet.json`）も認識し、`__MACOSX` は無視します。

## 設定（右クリック → 設定）

- **Claude Code** と **Codex** が同じ形のセクションを一つずつ持つ:
  - **ピルに表示** のオン・オフ
  - **データソース**: サブスク（ログイン中のアカウント）/ API（Admin API コスト — 今日・今月。月次予算を入れるとピルに `今月 $27.50 / $50` と出て、使用割合で「今月」の文字が黄・赤に変わり、金額はコーラルのまま）
  - **表示するゲージ** — Claude Code: セッション / 週間 / モデル別 / クレジット、Codex: セッション / 週間
  - **Admin API キー** と **月次予算** — Codex は **OpenAI Admin API キー**
- その下に急増感度、マウス挨拶の on/off。キャリブレーションは不要 — 急増アラートの上限はサーバーの % から学習します。

- **画面を歩き回る**: 右クリックメニューのチェック項目でオン・オフ（既定はオン）。マウスについて来る動きと
  モニター間のジャンプもこの項目に含まれる。macOS アクセシビリティの **視差効果を減らす**がオンなら動かない。
  自分で歩いて行った位置やジャンプ先は保存せず、ドラッグして置いた位置だけを覚える。

すべての設定・サイズ・位置は `~/.claude_pet.json` に保存されます。

## 制限（正直に）

- 数値はサーバーが計算した % そのままなので、Claude・Codex 自身の使用量画面と一致します。急増アラートはローカルログ基準なので、Web/デスクトップのチャット使用量は含まれません。
- Admin API のコストは Console の組織のもので、サブスクリプションの上限とは別です。
- Admin API キー（Anthropic・OpenAI）は `~/.claude_pet.json` に平文で保存されるため、個人のマシンでのみ使用してください。
