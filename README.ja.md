# 🐱 Claude Pet (Patch エディション)

[English](README.md) · [한국어](README.ko.md) · **日本語** · [Español](README.es.md)

Codex Pets のように、画面に浮かぶ Patch が Claude のトークン使用量を見守るデスクトップペット。
macOS ネイティブ（AppKit）描画 — ウィンドウ枠・背景・残像なし。

> 🧪 現在 **v0.1 (beta)** — 実験段階のため、挙動や表記が変わることがあります。

![Patch](preview.png)

## ダウンロードとインストール（推奨）

**Python 不要** — アプリに同梱されており、**Apple の公証（notarize）済み**なので Gatekeeper の警告なしで開けます。

1. [**Releases**](https://github.com/uygnoey/claude-pet/releases/latest) から `ClaudePet.zip` をダウンロード — **Intel Mac** の場合は `ClaudePet-universal.zip` を選んでください（v0.10 から提供）
2. 展開 → `ClaudePet.app` を **アプリケーション** フォルダへ移動 → ダブルクリック
3. macOS 12+（Apple Silicon; Intel は v0.10 から universal zip で対応）

### 権限（初回起動時）

ペットは **`~/.claude`（使用量ログ）とキーチェーンの OAuth トークン** だけを読みます。他のフォルダ（写真・ダウンロード・書類…）には一切触れません。初回起動時に出るのはこれだけです:

| ダイアログ | 内容 | 選ぶ |
|---|---|---|
| **キーチェーン** — "Claude Code-credentials" | 正確モードがサーバー計算の % を取得する OAuth トークン | **常に許可** |
| **「他のAppのデータ」** — `~/.claude` | 使用量ログの読み取り | **許可** |

- トークンは **起動ごとに1回だけ** 読み、署名済みアプリなので決定は保存され、二度と聞かれません。
- **写真／ダウンロード／ミュージック／デスクトップ／書類／iCloud／ネットワークボリュームのダイアログは出ません。**（以前はペットが `claude` CLI を子プロセスとして起動し、そのホームスキャンがアプリに帰属して出ていましたが、その CLI 呼び出しは既定でオフにしました。）
  - モデル別（Fable）の行を CLI で補完したい場合は `CLAUDE_PET_USE_CLI=1` を指定できますが、その場合フォルダのダイアログが再び出ます。

### Claude Code が必要です

このペットは **Claude Code の使用量**を表示するツールで、使用量データ（ログ・トークン）自体が Claude Code から得られます。そのため **サブスクリプションモードは Claude Code のインストールが前提**です。

- Claude Code が無い場合はゲージの代わりに **「Claude Code 未インストール」** と表示され、**右クリック →「⬇︎ Claude Code をインストール…」** で公式インストーラ（[`claude.ai/install.sh`](https://claude.ai/install.sh)）をターミナルで実行し、続けてログインします。
- インストール済みでログインだけ必要な場合は **右クリック →「🔑 Claude Code にログイン…」** ですぐログインできます。
- 完了すると再起動なしに次の更新で使用量が表示されます。
- 補足：**API モード**（右クリック → 設定 → Admin API キー）は Claude Code 無しでも動作します。

### アップデート

起動時に GitHub の最新リリースを確認し、新しいバージョンがあれば **右クリック →「⬆︎ 新しいバージョンをインストール」** でダウンロード・置換・再起動まで自動で行います。

## Windows（ベータ）

Windows 10/11（64 ビット）でも同じピル・散歩・設定・ペットが使えます。リリースごとに 2 つのファイルを公開します。

- **`claude-pet-win-setup.exe`** — インストーラー。現在のユーザーにインストールし（管理者権限不要）、スタートメニューと「アプリと機能」のアンインストール項目を作り、**サインイン時に Claude Pet を起動**するオプションがあります。
- **`claude-pet-win.zip`** — ポータブル／更新用。任意の場所に展開して `ClaudePet\ClaudePet.exe` を実行します。

**SmartScreen の警告について。** Windows 版はまだコード署名がないため、インストーラーや `ClaudePet.exe` を初めて実行すると *「Windows によって PC が保護されました」* が表示されます。**詳細情報** → **実行** の順にクリックしてください。ファイルごとに一度だけ表示され、発行元が不明であるという通知であって、有害なものを検出したという意味ではありません。ブラウザ（Edge）が同じ理由でダウンロードを止めた場合は **保持** → **そのまま保持** を選びます。コード署名が入るリリースからこの警告は出なくなります。

先に Windows で Claude Code にサインイン（`claude`）してから Claude Pet を起動してください。正確モードは Claude Code の資格情報ファイルを読み、推定モードは `%USERPROFILE%\.claude` 以下のログを読みます。自分のペットは `%USERPROFILE%\.claude_pet\pets\<名前>\` に入れます（右クリック → ペット → ペットを追加… でそのフォルダが開きます）。トレイアイコンは Windows の既定でタスクバーのオーバーフロー（`^`）内にあるので、引き出しておくと常に見えます。右クリック → 完全に削除… は設定とログを消し、プログラム本体は「アプリと機能」のアンインストールで削除します。

## ソースからビルド（開発者向け）

ソースからビルドするには **framework ビルドの Python** が必要です:

- **Homebrew**: `brew install python@3.13`（すでに framework ビルド）
- **pyenv**: `--enable-framework` 付きでインストール
  ```bash
  PYTHON_CONFIGURE_OPTS="--enable-framework" pyenv install 3.13.14 && pyenv global 3.13.14
  ```
  > ⚠️ システムの Python（`/usr/bin/python3`, 3.9）は pyobjc のビルドが壊れるため使わないでください。

```bash
./build_app.sh install     # ローカルでビルド+署名 → /Applications にインストールして実行
python3 claude_pet.py --report   # GUI なしのターミナルレポートのみ

./release.sh               # 配布用の自己完結アプリ（py2app）+ Developer ID 署名 + 公証 + zip
```
`release.sh` は初回のみ公証用の資格情報の登録が必要です（スクリプト冒頭のコメント参照）。

## 挙動

- **普段はじっとしている** — 最初のフレームで静止、25秒に1回だけ呼吸／まばたき
- **マウスが近づくと** — 手を振って挨拶（クールダウン30秒）
- **ときどき自分で歩き回る** — 普段はその場で休み、マウスが動いていると一度近づいてしばらく見つめ、
  そうでなければ画面のどこかをランダムに選んで散歩し、着いた場所でそのまま休む（元の場所には戻らない）。
  カーソルの上には歩いて行かず、つかんだりメニュー・設定を開くとその場で止まる
- **ときどきマウスについて来る** — 10〜20秒のあいだ距離を保ってゆっくり追いかけ、見つめてから止まった場所で休む。
  **モニターが複数あればときどき渡り歩く** — 小さくジャンプして薄れ、別の画面の安全な場所に現れる
- **歩くときはピルを畳んで** ペットだけが動く。着いたら畳んであっても使用量ピルをしばらく見せ、見終わると
  普段の状態に戻る
- **つかんでドラッグ** — 引っ張る方向へ走る。**ダブルクリック** = ジャンプ + **使用量を即時更新**（キャッシュ無視の再取得）
- **トークン消費が急増すると** — 体が警告色でパルス + パニック顔、ピルではそのゲージが ▲ 付きで赤くなる:
  - 🔴 セッション急増 / 🟣 モデル（Fable/Opus）急増 / 🟠 週間急増
- **セッションのリセットを検知すると** — 喜んでジャンプ

## 操作

- **スクロール（ペットの上で）**: サイズ変更（0.3×〜2.0×、保存。既定 0.5×）
- **クリック（⌄ ボタン）**: 使用量ピルの表示／非表示
- **ドラッグ**: 移動（位置を保存）
- **右クリック**: メニュー — 設定 / 表示・非表示 / 画面を歩き回る（オン・オフ） / サイズを元に戻す / ペット（選択・追加） / 完全に削除 / 終了 / アップデートを確認

## 使用量ピル

ペットのそばに小さなピルが一つ、二行:

- **1行目 — 使用量**: `セッション 42% · 週間 17% · Fable 12%` — セッション（5h）/ 週間合計 / 週間モデル別。モデル別ゲージは
  ログから上位ティア（fable → mythos → opus）を **自動検出**。API モードではコスト: `今日 $3.21 · 今月 $27.50`。
- **2行目 — リセット**: `リセット セッション 3時間42分後 · 週間 2日3時間後`（ローリング7日なら週間は `-`）。
- **数値の色 = 出どころ**: エメラルド = 正確モード（サーバー計算の %）、アンバー = ログ推定（値の前に ≈）、
  コーラル = API コスト。Claude Code のトークンが期限切れで推定になっている間は行末に ⚠。
- **ラベルの色 = 残量**: 白、50% から黄、85% から赤 — 急増中のゲージは ▲ 付きで赤。
- 文字は同梱の **Pretendard**（SIL Open Font License）で描くので、どのマシンでも同じ見た目。

## 自分のペットを入れる

右クリック → **ペット** に内蔵の猫と `~/.claude_pet/pets/` 以下の全フォルダが並び、**ペットを追加…** でそのフォルダが
フォーマット説明の README と一緒に開きます。ペットは `pet.json` + `spritesheet.webp` を入れたフォルダ一つです（シートの
規約は README に）。一覧はメニューを開くたびに読み直すので、再起動なしですぐ現れます。zip を展開して一段深くなった
フォルダ（`pets/name/name/pet.json`）も認識し、`__MACOSX` は無視します。

## 設定（右クリック → 設定）

- **データソース**: サブスクリプション（Claude Code のログ）/ API（Admin API コスト — 今日・今月。月次予算を入れるとピルに `今月 $27.50 / $50` と出て、使用割合で「今月」の文字が黄・赤に変わり、金額はコーラルのまま）
- **🔧 キャリブレーション（最重要！）**: トークンの上限は Anthropic 非公開で誰も分かりません。
  代わりに Claude アプリの **設定 > 使用状況** に表示される % を入力して保存すると、アプリが
  `上限 = 現在の使用量 ÷ %` を逆算します。入力した項目だけが反映されます。
- **週間リセットの曜日／時刻**: アプリに「土 20:00 にリセット」と出るなら 土曜/20時 に設定。未設定なら7日ローリング。
- モデルキーワード（auto 推奨）、急増感度、マウス挨拶の on/off、Admin API キー、月次予算

- **画面を歩き回る**: 右クリックメニューのチェック項目でオン・オフ（既定はオン）。マウスについて来る動きと
  モニター間のジャンプもこの項目に含まれる。macOS アクセシビリティの **視差効果を減らす**がオンなら動かない。
  自分で歩いて行った位置やジャンプ先は保存せず、ドラッグして置いた位置だけを覚える。

すべての設定・サイズ・位置は `~/.claude_pet.json` に保存されます。

## 制限（正直に）

- データは Claude Code のローカルログ基準 — Web/デスクトップのチャット使用量は含まれません。そのためアプリの % より低く出ることがあり、定期的に再キャリブレーションすると正確になります。
- Admin API のコストは Console の組織のもので、サブスクリプションの上限とは別です。
- Admin API キーは `~/.claude_pet.json` に平文で保存されるため、個人のマシンでのみ使用してください。
